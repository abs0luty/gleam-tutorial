

# Tutorial del lenguaje Gleam

## Estado

El tutorial está en desarrollo activo y no está terminado.

## Construcción local

Si deseas construir el libro desde el código fuente en tu máquina, clona el repositorio y ejecuta `mdbook build`:

```
git clone https://github.com/abs0luty/gleam-tutorial
cd gleam-tutorial
mdbook build
```

Luego, accede a `book/index.html`. Como alternativa, puedes ejecutar `mdbook serve`, lo que iniciará el servidor de `mdbook` en `localhost`.
